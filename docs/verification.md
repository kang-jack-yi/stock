## 数据准确性核对

- 全市场快照 5,571 只；上涨 2,566、下跌 2,824、平盘 175、无有效报价 6，四类合计等于覆盖数；涨跌分布也按互斥区间核对。完整分页获取后再筛选，末页匹配不会漏掉。
- 新浪行业 49 项、概念 175 项。风电成分实际 176 只、汇总榜样本 100 只；9 页合计 176 个唯一代码，完整成交额/成交量与全页求和一致。创新药实际 148 只而汇总榜为 100 只。电子信息实际 247 只、源数量接口 245 只、汇总榜 247 只，第 13 页有效。界面及字段注释分别标明这些口径。
- 个股与指数 K 线原始成交量已为股；上证指数行情快照原始为手、深市指数行情快照原始为股。实际核对上证、深证、创业板和沪深 300 的收盘快照与日 K、5 分钟 K 合计，修正指数转换规则。
- 实际分时文件解出 241 个有效分钟点，当日末点与行情收盘价格一致；数据日期明确展示，未保证源站盘中刷新频率。
- 股票比较先求有效共同日期交集，再用相同首日归一化；数据表与图表采用同一序列。缺失或不足两个共同日期会报错，不插值造数据。未复权涨跌不等同于含分红总回报。
- 财经资讯使用新浪财经滚动页对应三类接口，只显示安全 HTTPS 原文链接及标题、时间、媒体，未转载全文。

## 运行边界

账号系统当前使用单实例 SQLite，没有邮件验证、找回密码或第三方登录。新浪公开免费接口没有可依赖的 SLA；商业使用授权、稳定实时数据、复权完整历史和多实例数据库需在上线阶段另行处理。详见 README 的接口、部署和缓存说明。
